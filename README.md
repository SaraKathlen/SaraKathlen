## ⛤ 01 // Sobre mim

Olá! Sou Sara Kathlen, estudante do terceiro semestre de Engenharia de Software, apaixonada por tecnologia, desenvolvimento de sistemas e criação de experiências digitais.

Acredito que desenvolver software vai além de escrever códigos. Envolve compreender problemas, estruturar soluções eficientes e criar experiências que unam funcionalidade, criatividade e identidade visual.

Durante minha trajetória acadêmica, venho aprimorando meus conhecimentos em programação, desenvolvimento web, estruturas de dados e organização de sistemas.

Valorizo códigos limpos, interfaces intuitivas, boas práticas de desenvolvimento e o aprendizado contínuo.

Atualmente, busco uma oportunidade de **estágio em Engenharia de Software ou Desenvolvimento Web**, na qual possa aplicar meus conhecimentos, colaborar com equipes e evoluir profissionalmente.
